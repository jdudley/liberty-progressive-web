# Liberty Progressive Framework

**Live site: [https://jdudley.github.io/liberty-progressive-web/](https://jdudley.github.io/liberty-progressive-web/)**

A political philosophy grounded in freedom, fallibilism, and decentralized problem-solving.

## What is Liberty Progressivism?

Liberty Progressivism descends from the Enlightenment tradition and critical rationalism. It holds that **the means of progress are more fundamental than any particular progressive outcome**. If we protect the mechanisms of error correction—free speech, distributed power, decentralized experimentation—good outcomes can emerge from the iterative process of learning.

## The Two Principal Axes

Modern progressivism can be mapped along two key dimensions:

### Liberty ↔ Statist
Where do you locate problem-solving capacity?
- **Liberty**: Contestable, plural, exit-based systems
- **Statist**: Centralized coordination with uniform standards and expert control

### Reformer ↔ Revolutionary
How should change occur?
- **Reformer**: Iterative error correction with reversibility and dissent tolerance
- **Revolutionary**: Urgent transformation with moral certainty

## The Four Quadrants

| | Reformer | Revolutionary |
|---|---|---|
| **Liberty** | Epistemic Reformers | Open System Radicals |
| **Statist** | Technocratic Pragmatists | Moral Centralizers |

## The Canonical Document

`docs/framework.md` is the canonical framework text. Everything readers see is
built from it:

- the typeset PDF (`dist/Liberty_Progressive_Framework_v<version>.pdf`),
- the site's full-framework page (`framework.html`, generated by injecting the
  document body into `framework.template.html`),
- Figures 1 and 2, generated from `figures/axes.json` and `figures/people.json`
  by `figures/generate.js` so placement changes are reviewable one-line diffs.

To edit the framework, open a branch + PR against `docs/framework.md`. For a
release, bump `version:` in its frontmatter, tag, and attach the built PDF to a
GitHub Release. Corrections are recorded in `CHANGELOG.md` with credit — the
framework is versioned like software because it is treated like a conjecture.

## Building

```
./build.sh
```

Requires `node`, `pandoc`, and `weasyprint`. Outputs go to `dist/` (gitignored)
plus the generated `framework.html` (also gitignored). Straight quotes in the
source are restored to smart quotes at build time.

## Working with Claude Code

This project includes a `CLAUDE.md` file and `context/` folder specifically designed to help Claude Code understand the project when making edits. The context includes:

- Framework summary and intellectual foundations
- Quiz design principles and scoring logic
- Style guidelines and common tasks

When using Claude Code, it will automatically read `CLAUDE.md` to understand the project context.

## Hosting

The site deploys via GitHub Actions (`.github/workflows/build.yml`): every push
to `main` builds the PDF, figures, and framework page, then publishes to GitHub
Pages. Repo Settings → Pages is set to "GitHub Actions" as the source.
